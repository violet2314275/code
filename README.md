# AI-Driven Embedded Architecture: STM32 & 74HC595 Light Cube

> **本项目是一个由 AI Agent 深度驱动的嵌入式开发实践，旨在探索利用长链推理解决复杂硬件时序控制与空间逻辑映射。**

## 项目概览
本项目基于 **STM32** 核心控制器，通过级联 **6 片 74HC595 移位寄存器**，实现了对 4x4x4 空间矢量光立方的精确驱动。项目核心亮点在于引入了基于 Cursor 与 Claude Code 的 **Agent 自动化开发工作流**。

## 🛠 硬件架构
- **MCU**: STM32F103 (Cortex-M3)
- **驱动控制**: 74HC595 (x6 级联)
- **显示拓扑**: 4x4x4 空间 LED 矩阵
- **通信协议**: 高速 SPI 模拟时序

## AI Agent 工作流 (核心特色)
本项目通过构建特定的 AI 智能体链条，解决了以下技术难点：
1. **硬件规格解析**: 自动解析 74HC595 数据手册（Datasheet），提取纳秒级时序约束。
2. **时序逻辑合成**: 利用长链推理生成 6 片级联下的比特对齐算法。
3. **坐标映射重构**: 将三维空间坐标 (x, y, z) 自动转换为串行移位指令，实现 0 误差映射。

## 仓库结构
- `/src`: 核心控制逻辑与动画算法
- `/drivers`: AI 生成的 74HC595 硬件抽象层驱动
- `/logs`: **AI Agent 协同开发过程记录 (用于 Token 申请证明)**
- `/docs`: 硬件原图说明与开发文档
