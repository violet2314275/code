# code
项目描述： 我构建了一套基于 Cursor 与 Claude Code 协同的“嵌入式智能开发工作流”，专注于解决在 STM32 底层驱动开发中，寄存器配置与复杂硬件时序逻辑（如多片 74HC595 级联）映射效率低、易出错的核心痛点。  核心逻辑： 采用了“需求解构—时序仿真逻辑生成—代码闭环验证”的长链推理流程。利用 AI Agent 深度理解硬件原理图规格，自动生成高可靠性的位移寄存器驱动算法及三维坐标映射逻辑。通过多 Agent 协作，由一个 Agent 负责底层驱动生成的准确性，另一个 Agent 负责业务层动画逻辑的抽象。  具体成果： 在 4x4x4 空间光立方项目中，该工作流将底层驱动与显示算法的开发周期缩短了 70%，实现了复杂三维扫描逻辑的“零调试”一次性通过。
